# Changelog

## 1.0.0

- Initial Enchanted Forest Windows desktop application with eight sections, SQLite data, task/event management, recurrence, focus sessions, reminders, backups and search.
- Google Calendar system-browser sign-in, durable sync queue, conflict review and a six-step setup guide.
- One-click per-user installer configuration, Desktop/Start menu shortcuts and GitHub Windows draft-release workflow.

See `docs/VERIFICATION.md` for actual verification and limitations. The installer and remote GitHub workflow still require an unrestricted build and native installation checks before publishing the first release.
