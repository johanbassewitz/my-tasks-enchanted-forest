# Implementation plan

1. Shared cloud contract and checkpoint: define strict API schema for account, Paddle status, AI quota/input/output. Preserve 1.2.1 working changes.
2. Worker backend: auth, D1 migration, Paddle checkout/webhooks/reconciliation, quotas with atomic reservation/idempotency, bounded OpenRouter requests, deployment instructions and tests. Keys and paid pricing configured only on server. Fail closed when absent. Account quotas do not reset on reinstall.
3. Electron/UI integration: protected token store, validated HTTPS-only service calls, external Paddle checkout, Account UI, AI suggestion review and atomic idempotent local import, Shop Paddle copy. Remove native Store commerce, preserve startup and preview mode. Update packaging/version and docs.
4. Validate: full tests, build, packaging, independent security review; fix findings. Update both release branches with connector commits, run Windows CI, deliver installer artifact. No release, no deployment, no live charge.

Checks: auth expiry/rate limiting; webhook signatures/duplicates/out-of-order/refunds; concurrent quotas, retries, malformed model output, global spend cap; no secrets in installer/backups; invalid URLs rejected; AI user confirmation and offline core; existing regression suite.
