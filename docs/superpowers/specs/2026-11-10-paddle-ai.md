# Paddle-only commerce and optional AI

User authorization: switch payments exclusively to Paddle and implement the previously discussed OpenRouter AI feature. Prepare and test only; never publish, charge, send real email or deploy without configured services. Existing release branches are authorized test build targets. Preserve local planning and all 1.2.1 changes.

Implementation decisions: Cloudflare Worker + D1; verified-email accounts via one-time codes for optional cloud features; 5 free successful AI actions per UTC calendar month, configurable server-side; one credit per bounded successful goal/notes-to-tasks action; paid 50-action packs configurable in Paddle. No hardcoded retail price, no live model assumed. AI receives only explicitly entered text, date/timezone; never entire database. Suggestions require selection/review before creating ordinary local tasks. OpenRouter and Paddle secrets remain server-only. No automatic release or live purchases.

Paddle checkout opens default browser, server creates transaction from allowed product keys and binds account independently of customer-supplied custom_data. Signed webhook plus authoritative API reconciliation controls licenses and refunds. No client-side unlock or trust in checkout success redirect. Subscriptions active only during verified paid period; refund revokes affected grant. Purchases restore after verified-email sign-in. Secure local token via Electron safeStorage; tokens absent from backups. Bounded signed offline license snapshot, no arbitrary local grants.

No hosted backend or credentials currently provided. Unconfigured preview must clearly explain online services unavailable and never simulate real AI, purchases or account messages. Existing offline packs stay available in explicit preview. Store startup helper retained only for Windows startup; remove Microsoft purchase and licensing paths entirely. Store package identity independent of billing configuration.
